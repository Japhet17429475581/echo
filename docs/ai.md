# Ограниченные AI-функции

DeepSeek выключен по умолчанию. Поиск, очередь, нормализация, объединение, фильтры, стандартные объяснения, все отчёты и age работают без AI. Обращения проходят только через `Gateway` в `ai.py`; SDK с дополнительными внутренними retries не используется.

## Передача данных

- Описание: название площадки, её домен, очищенный фрагмент одобренной официальной страницы до 1800 символов, язык. Одним JSON-ответом возвращаются описание, категория, до трёх возможностей и недостаточность фактов.
- Перевод: уже проверенное описание и возможности площадки; источники и происхождение сохраняет приложение.
- Нестандартное техническое объяснение по кнопке: enum-статусы, движок, HTTP-код, безопасный тип ошибки, обезличенный тип redirect и известное правило проверки. Модель не меняет статус.
- Intent-parser: только при явном включении `ECHO_AI_INTENTS` и пользовательского AI; короткое текущее сообщение после маскирования известных ников, Telegram ID/username/имени, URL, email и номеров. История чата не передаётся. При небезопасном/слишком длинном тексте используются кнопки. AI-intent сам ничего не выполняет.

Не передаются ники из выдачи, найденные профильные URL, биографии, сообщения со страниц, заметки, история поисков, заголовки авторизации сайтов или полный HTML. Полезный текст официального сайта — недоверенные данные, а не инструкции. У модели нет инструментов, shell, SQL или сетевого доступа от приложения.

## Когда запроса нет

AI выключен, отсутствует ключ, пользователь не согласился, операция отменена, есть актуальный кэш/ручная запись, lock занят, нет одобренного источника, превышен входной предел, достигнут лимит/бюджет, нет свободного параллельного слота или открыт circuit breaker. Невозможность получить описание не меняет результат поиска.

Начальный каталог из восьми сервисов проверен вручную и содержит оба языка; для него AI не нужен. Неизвестные площадки показывают «Описание пока недоступно». Оператор может расширить каталог проверенными официальными источниками.

## Кэш

Каталог общий для пользователей, ключ: site ID + язык + версия схемы + версия промпта. Актуальная запись не вызывает LLM. Просроченная допустимая запись остаётся доступной сразу, фоновое обогащение обновляет её отдельно. Неудачные обновления получают отрицательный TTL; ручные записи AI не переписывает. Redis lock с token и TTL защищает singleflight, освобождение проверяет владельца. Стандартные объяснения локальные; AI-объяснения кэшируются по всем очищенным фактам, языку, модели и версии промпта. Пользовательские intent-тексты не кэшируются.

## Валидация и fallback

JSON-object, enum, `extra=forbid`, пределы длины и числа элементов, проверка языка, отсутствие обрезанного ответа/отказа. Markdown, массивы, неизвестные поля и категории отвергаются. Допускается одна структурная repair-попытка без передачи невалидного ответа обратно модели. Затем — каталог, шаблоны и нейтральное сообщение о недоступности. Проверка языка консервативная по письменности, а не полноценный лингвистический классификатор.

## Расход

Перед запросом Redis Lua атомарно резервирует максимальное число внешних попыток, включая транспортные повторы и одну repair, и денежную верхнюю оценку при заданных тарифах. Резерв учитывает UTF-8 вход и максимальный вывод. Ограничены глобальные/пользовательские/операционные запросы за UTC-сутки, параллельные запросы и `max_tokens`. Фоновые обновления проходят те же ограничения.

После ответа возвращается только неиспользованная часть резерва. Без usage и после таймаута отправленного запроса расход остаётся консервативной оценкой; нулевой точный расход не записывается. При падении процесса резервы не освобождаются досрочно. Они могут уменьшить доступный бюджет сильнее фактического расхода, что безопаснее перерасхода.

Тарифы **не зашиты**. `ECHO_AI_INPUT_USD_MILLION`, `ECHO_AI_OUTPUT_USD_MILLION` и `ECHO_AI_PRICE_DATE` задаёт оператор по текущему договору. Без тарифов денежная стоимость неизвестна; пределы запросов и вывода работают. Строгий валютный предел зависит от достоверности тарифов, tokenizer/usage и биллинга провайдера; сравнивайте оценку с кабинетом DeepSeek.

Повторы: только ограниченные сетевые/429/5xx; Retry-After поддерживает секунды и HTTP-date, ограничивает задержку, отвергает NaN/Infinity/отрицательные значения. 400/401/403/404/422 не повторяются. Circuit breaker и конфигурационные ошибки временно останавливают новые обращения. SDK retry multiplication отсутствует.

## Настройки и наблюдение

Все `ECHO_AI_*`, `ECHO_CATALOG_*`, `ECHO_SOURCE_MAX_BYTES` перечислены в `configuration.md`. Модель и endpoint сменяемые; запрос использует документированные `response_format={type:json_object}` и `max_tokens`, текущий default — `deepseek-flash`, без зашитой цены.

`/admin` либо `python -m echo.main admin`: cache hit rate, число внешних попыток, известный usage, время, outcomes, резерв/расход, остаток бюджета и circuit breaker. Таблица `ai_calls` не хранит prompt или ответ. Для сверки суммируйте `attempts`, проверяйте `estimated` и сравнивайте с кабинетом провайдера.

Шесть новых инструментов, папки, сравнение и пакеты не вызывают LLM. EXIF/GPS, файлы, OCR-текст, QR и содержимое папок не направляются провайдеру автоматически. Их сводки и ошибки — локальные RU/EN шаблоны. Дополнительный AI-пересказ страниц не добавлен; расширения AI должны использовать этот же gateway, согласие, очистку, кэш и бюджет.
