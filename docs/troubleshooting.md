# Диагностика

## Контейнер не стартует

`No module named 'echo'` на Bothost: исходники монтируются в `/app` и скрывают окружение, если оно было собрано внутри `/app/.venv`. Исправленный образ хранит окружение в `/opt/echo`. Включите свой Dockerfile и пересоберите деплой из актуальной ветки `main`. Точка входа — корневой `main.py` или CMD из Dockerfile; полный порядок — [bothost.md](bothost.md).

`docker compose ps`, затем `docker compose logs --tail=50 migrate worker bot`. Ошибки выводятся безопасным типом без секретов. Убедитесь, что Docker Desktop работает в Linux mode, установлен Compose v2.20+, `.env` создан, `ECHO_DATABASE_URL` содержит готовую строку PostgreSQL, а токен получен для вашего бота. Спецсимволы в пароле строки должны быть URL-encoded; сохраняйте параметры SSL, указанные провайдером. Отдельная Windows-ошибка `docker compose` может означать отсутствие CLI plugin в конфигурации Docker.

`migrate` должен завершиться с кодом 0. Проверка БД/Redis из приложения: `docker compose run --rm --no-deps worker python -m echo.main health`. Для внешней БД проверьте её доступность, SSL и правила сетевого доступа у провайдера. Только при использовании `local-db`: `docker compose --profile local-db exec postgres pg_isready -U echo -d echo`. Redis: `docker compose exec redis redis-cli ping`. Не публикуйте их порты для диагностики.

## Telegram не отвечает

Проверьте токен, исходящий доступ к `api.telegram.org`, отсутствие другой polling-копии и использование личного чата. Telegram flood control временно замедляет редактирование прогресса. Отправленные результаты доступны через `/tasks` после восстановления polling. Прокси из пользовательского сообщения не применяются.

## Очередь или PARTIAL

`/admin` показывает количество задач, worker heartbeat, агрегаты движков. QUEUED может ожидать глобальный слот. После падения worker подождите `ECHO_LEASE_SECONDS` и очередной цикл; затем задача продолжится, сохранив готовые проверки. PARTIAL с `timeout` означает, что истёк общий таймаут движка; уменьшите покрытие или разумно увеличьте `ECHO_ENGINE_TIMEOUT`. Не повышайте нагрузку ради обхода 403/429.

`targets_unavailable` при повторе: состав площадок изменился или запись исключена безопасными фильтрами. `engine_failure`/`adapter_error`: проверьте версии/lock-файлы, лимит памяти и выполните `compose.test.yaml`. Нативный stderr upstream намеренно не логируется, чтобы не раскрывать URL и профили; воспроизводите контракт с синтетическим локальным fixture.

## Описание отсутствует

Это допустимый fallback. Сначала используется общий каталог. Незнакомая площадка требует одобренного официального источника от администратора. AI не загружает найденный профиль и не отвечает «по памяти». Если AI включён, проверьте бюджет, circuit breaker, endpoint, модель, лимиты и отрицательный TTL. Ручное описание не обновляется AI.

## Экспорт

PDF требует кириллический TTF; runtime включает DejaVu Sans. Недопустимый ключ проверяется age; поддерживаются только `age1…` X25519 public recipients. `age_unavailable`: пересоберите официальный Dockerfile или установите стандартную age. Невозможно расшифровать: используйте identity для именно того получателя, fingerprint которого подтвердили. Потерянный приватный ключ сервер восстановить не может.

Слишком большой файл: CSV/JSON обычно компактнее PDF/HTML; уменьшите покрытие следующего поиска. Бот не делит plaintext по случайным общедоступным ссылкам. Длинный URL копируется через отдельное code-сообщение, если CopyTextButton не вмещает его.

## Удаление и восстановление

Просроченные задачи сразу недоступны через проверку TTL; физическое удаление записей выполняет worker. Удалённая задача не сохраняется повторно старым worker. Восстановление backup может вернуть старые данные; примените журнал удаления до возобновления сервиса. Очистка не отзывает уже скачанные отчёты.

## Инструмент недоступен или достиг лимита

Capabilities появляются после probe worker и обновляются heartbeat. Проверьте `python -m echo.main admin`, `ECHO_<ID>_ENABLED`, `/opt/tools/bin/python`, ExifTool/Tesseract/WhatWeb, eng/rus traineddata и Landlock ABI ≥3/libseccomp2. На Windows без Linux containers изоляция не поддерживается; модуль должен оставаться недоступным. Не отключайте sandbox ради запуска на старом ядре. После установки зависимостей перезапустите worker. Остальные модули не требуют отсутствующего инструмента.

`resource_limit` / `output_limit`: уменьшите изображение, число вариантов или материал экспорта. OCR принимает один кадр и до 8 млн пикселей, не PDF. EXIF требует документ: Telegram photo может изменить метаданные. Пустой QR/OCR — допустимый результат, не ошибка сети. `storage_full`: удалите ненужные задачи/материалы, проверьте пользовательскую и общую квоту, свободное место files и tmpfs. Не удаляйте scratch действующей задачи вручную: штатный cleanup проверяет lease. Низкий лимит памяти контейнера может завершить worker целиком; оцените общий бюджет перед повышением параллельности.

`source_unavailable` / запрет URL: допустимы публичные HTTP(S), стандартные порты, все DNS и redirects должны проходить политику. Сжатые/слишком большие ответы ограничены, CAPTCHA/авторизация не обходятся. Для воспроизведения используйте `tests/test_tools_smoke.py`, без чужих доменов. Форматы, ограничения и обновление — [modules.md](modules.md).
